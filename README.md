# 📱 My APK - Compilador de Scratch 3 a Android (APK)

**My APK** es una plataforma web interactiva y **100% gratuita** diseñada para convertir proyectos de **Scratch 3 (`.sb3`)** en archivos ejecutables y empaquetados para **Android (APK)** utilizando el alto rendimiento del motor **TurboWarp** y la arquitectura de contenedor nativo de **Apache Cordova**.

---

## 🚀 Características Principales

* ** Gratuito y Libre de Suscripciones:** No requiere pagos, suscripciones ni cuentas de usuario.
* ** Motor TurboWarp Integrado:** Convierte tu proyecto de Scratch a código HTML5/JavaScript de alto rendimiento (hasta 60 FPS).
* ** Edición Interactiva de Permisos:** Permite habilitar o deshabilitar fácilmente permisos de hardware en Android:
  * 🎙️ **Micrófono** (`android.permission.RECORD_AUDIO`)
  * 📷 **Cámara** (`android.permission.CAMERA`)
  * 🌐 **Internet** (`android.permission.INTERNET`)
* ** Previsualización en Tiempo Real:** Prueba tu juego de Scratch directamente dentro de la plataforma antes de compilar.
* ** Estructura APK Autónoma:** Genera el archivo manifiesto (`AndroidManifest.xml`) e inyecta los binarios del proyecto automáticamente.

---

## 🛠️ ¿Cómo Funciona?

1. **Scratch 3 (`.sb3`):** Cargas tu archivo de juego o aplicación.
2. **TurboWarp Engine:** Procesa los bloques y assets para renderizarlos a máxima velocidad.
3. **Apache Cordova / Manifest Injector:** Crea la envoltura nativa de Android inyectando los permisos seleccionados en el archivo `AndroidManifest.xml`.
4. **Descarga:** Obtienes tu paquete compilado listo para desplegar e instalar.
